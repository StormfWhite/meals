# Meal Planner (phone)

Storm's Meal Planner for phones: the laptop app's own Python package and FastAPI routes run in the
browser (Pyodide), behind the laptop app's own front end, on data shared through Dropbox.
Rebuild from the laptop source with `./build.sh`. Nothing personal is stored here.
Open https://stormfwhite.github.io/meals/ → Share → Add to Home Screen.
